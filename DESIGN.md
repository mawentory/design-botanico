# Botanical

> Cream and terracotta

A standalone design reference for **Botanical**, one of ten designs built for
MarvinRouter. This repo holds the complete token set, the identity rules that
tokens cannot express, and a component gallery that renders every part of the
system.

Open `index.html` — there is no build step.

---

## Where it comes from

Botanical illustration and natural-dye packaging: cream paper, terracotta and olive, and the softer edges of printed matter.

## Palette

Cream ground with terracotta (#b4673a) as the signal and olive in the ink. Nothing is pure grey — every neutral is warmed.

Core roles in this design:

| Token | Value | Role |
| --- | --- | --- |
| `--paper` | `#f3efe4` | Page ground |
| `--sheet` | `#fbf8f0` | Raised surfaces |
| `--ink` | `#2a3226` | Primary text |
| `--ink-2` | `#56604d` | Secondary text |
| `--ink-3` | `#7e8873` | Muted text and labels |
| `--rule` | `#d3cdbb` | Borders and dividers |
| `--signal` | `#b4673a` | Action and focus |
| `--board` | `#2a3226` | Code and inverted panels |

The design defines 66 tokens. 13 further values are
*derived* from them for contrast, and are marked as such in `theme.css` and at
the end of the gallery. `theme.css` is the source of truth; the gallery prints
every value it contains.

## Typography

Fraunces for display and body with its optical sizing, giving a literary voice that still reads cleanly in a table.

Fonts shipped in this repo: Fraunces, IBM Plex Mono. Each is a latin subset in
`fonts/`, declared with `@font-face` and `font-display: swap` so the page never
blocks on a webfont. They are redistributed under the SIL Open Font License
1.1; see `fonts/LICENSE.txt` for the copyright notices.

| Token | Value |
| --- | --- |
| `--font` | `"Fraunces", Georgia, "Bitter", serif` |
| `--mono` | `"IBM Plex Mono", ui-monospace, "Cascadia Mono", monospace` |
| `--display` | `var(--font)` |
| `--display-weight` | `600` |

## Accessibility

Dark olive on cream is about 12:1. The softer shadow never reduces edge contrast below 3:1 against the ground.

Where the designer's colour could not carry text, this repo ships a derived
value rather than changing the palette:

| Token | Chosen | Derived for text | Why |
| --- | --- | --- | --- |
| `--signal` | `#b4673a` | `--signal-text` `#9a5832` | The raw signal is only 3.70:1 on this paper, unreadable as text. |
| `--ink-3` | `#7e8873` | `--ink-3-text` `#606757` | Muted labels sit on panels as well as the page. |
| `--add` / `--del` | `#4f7a46` / `#a8452f` | `--add-text` / `--del-text` | Success and error text must clear 4.5:1 on a tinted badge. |
| `--code-str` | `#d9a566` | `--board-key-text` | Code keys are small and often on a diff tint. |
| focus ring | — | `--focus-ring` `#b4673a` | A ring has to be visible on page *and* panel. |

Every derived value is generated by pushing the original colour toward the
opposite end of the ramp until it clears its floor, so it stays as close to the
designer's intent as the contrast minimum allows.

### Conventions this design keeps

- **Status is never colour alone.** Every badge pairs its colour with a word, and
  a dot is always accompanied by a label.
- **Focus is always visible.** `:focus-visible` draws a 3px `--focus-ring` ring
  with a 2px offset, on every interactive element.
- **Targets are at least 44px tall** for primary controls and 34px for small ones
  used inside dense areas.
- **Progress carries its value in text**, not only in the width of a bar.
- **One `h1` per page and no skipped heading levels** — the gallery is checked
  for both.
- **Motion respects `prefers-reduced-motion`** — transitions collapse to
  effectively zero rather than disappearing, so state changes stay legible.

## Files

```
index.html   component gallery — every component, this design
design.css   component styles, written against tokens only
theme.css    the 66 design tokens
fonts.css    @font-face declarations
fonts/       latin-subset woff2 files
```

`design.css` contains no colour, radius or font literal. That is deliberate: the
file is shared across all ten designs, and only `theme.css` differs.

## Using it elsewhere

Copy `theme.css` and set `data-theme="botanico"` on your root element. The
tokens are namespaced by attribute, so this file can sit alongside another design
in the same page.
